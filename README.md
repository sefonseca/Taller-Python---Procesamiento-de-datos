## Descripción

Cada taller está desarrollado en formato Jupyter Notebook (`.ipynb`) para poder ejecutarse directamente en Google Colab.

## Talleres

### Taller 1 - Ejercicios básicos

Introducción a Python mediante ejercicios básicos de programación.

### Taller 2 - Tuplas

Se trabajan conceptos relacionados con tuplas:

- Creación de tuplas
- Índices
- Índices negativos
- Slicing
- Concatenación
- Longitud de una tupla
- Ordenamiento
- Tuplas anidadas

### Taller 3 - Listas

Se practican operaciones básicas con listas:

- Creación de listas
- Acceso mediante índices
- Slicing
- Concatenación
- Listas con diferentes tipos de datos
- Listas anidadas

### Taller 4 - Conjuntos

Se trabajan diferentes operaciones con conjuntos:

- Creación de conjuntos
- Conversión de listas a conjuntos
- Eliminación de elementos repetidos
- Unión de conjuntos
- Subconjuntos
- Métodos de conjuntos

### Taller 5 - Diccionarios

Se practican operaciones con diccionarios:

- Creación de diccionarios
- Llaves y valores
- Acceso mediante llaves
- Método `keys()`
- Método `values()`

### Taller 6 - Condiciones

Se desarrollan ejercicios utilizando estructuras condicionales:

- `if`
- `if-else`
- Operadores de comparación
- Operadores lógicos

### Taller 7 - Bucles

Se practican estructuras repetitivas:

- Bucle `for`
- Bucle `while`
- Función `range()`
- Uso de `break`
- Recorrido de listas

### Taller 8 - Funciones

Se desarrollan funciones en Python utilizando:

- Definición de funciones
- Parámetros
- Retorno de valores
- Operaciones con diferentes tipos de datos

### Taller 9 - Clases

Se introducen conceptos de programación orientada a objetos:

- Creación de clases
- Constructores
- Atributos
- Métodos
- Creación de objetos
- Modificación de atributos
- Uso de Matplotlib para representar una elipse

## Ejecución

Los archivos `.ipynb` pueden abrirse directamente en Google Colab.

Para ejecutar un taller:

1. Descargar o abrir el archivo `.ipynb`.
2. Abrirlo utilizando Google Colab.
3. Ejecutar las celdas en orden.
4. Revisar los resultados obtenidos en cada ejercicio.
